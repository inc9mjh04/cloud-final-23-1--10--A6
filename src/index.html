云计算期末大作业 - Docker镜像构建 实施流程

流程总述
围绕Docker镜像构建作业，梳理仓库创建、工具准备、项目搭建、远程连接、实验实施、提交运维六大核心环节，形成标准化作业流程。
六大核心实施步骤
步骤1：创建GitHub仓库
搭建作业代码托管基础，创建符合命名规范的公开仓库。
核心操作
  • 创建公开仓库，按规范命名（如cloud-final-23计科1-第01组-A6）
  • 填写作业相关描述，不初始化README等文件
  • 保存仓库远程地址，用于后续关联
步骤2：部署基础工具
安装版本控制（Git）和容器化（Docker）核心工具。
Git安装
  • 下载官方安装包，默认配置完成安装
Docker Desktop安装
  • 下载安装后重启，验证启动状态
  • 家庭版需装WSL2，专业版开启Hyper-V
步骤3：搭建本地项目
按规范创建项目目录结构，准备基础文档文件。
目录结构
cloud-final-A6/
├── report/（作业报告）
├── slides/（演示文稿）
├── src/（实验代码）
├── assets/（资源文件）
基础文件
  • report目录：作业报告MD文件
  • 根目录：README.md、选题列表.md
步骤4：关联远程仓库
建立本地项目与GitHub仓库的版本控制关联。
Git命令行（推荐）
# 初始化→提交→关联远程→推送主分支
git init && git add . && git commit -m "初始提交"
git remote add origin 仓库地址 && git push -u origin main
# 创建并推送组分支
git checkout -b 组分支名 && git push -u origin 组分支名
图形化方式
  • GitHub Desktop克隆仓库，复制文件后提交推送
步骤5：实施Docker实验
编写镜像配置和Web页面，完成构建与运行验证。
核心配置
# src/Dockerfile（基于Nginx构建Web镜像）
FROM nginx:alpine
COPY index.html /usr/share/nginx/html/
EXPOSE 80
构建运行
# 构建镜像→运行容器→验证访问
docker build -t my-webapp:v1 .
docker run -d -p 8080:80 webapp
# 访问 http://localhost:8080 验证效果
步骤6：提交与运维
实时提交作业进度，解决常见版本控制/容器化问题。
进度提交
git add . && git commit -m "更新描述" && git push
常见问题
  • 权限报错：配置git用户名/邮箱
  • 推送失败：拉取远程分支最新内容
  • Docker启动失败：检查虚拟化配置
